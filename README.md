# AI Audit Mini-Project: Adult Income Dataset

**Course:** Information Systems Audit - Axis 2 (Auditing AI Systems)
**Team:** Abada Zine Eddine Ahmed & Naib Raja
**Date:** November 3, 2026

## Project Objective
Audit of a binary classification model (Adult Income dataset) focusing on:
- Data Quality
- Bias and Fairness (Fairlearn)
- Explainability (SHAP, LIME)
- Robustness

## Repository Structure
- `data/`: Raw and processed datasets (gitignored)
- `src/`: Python scripts for data prep, training, and fairness audit
- `notebooks/`: Jupyter notebooks for exploration and reporting
- `reports/`: Generated figures and audit summary
- `docs/`: Project framing document
